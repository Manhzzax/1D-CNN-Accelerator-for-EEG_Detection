# Literature Evidence

Maintain two non-interchangeable tables:

- **L1 reported literature:** verified values from papers under heterogeneous
  protocols. Each card records DOI/URL, dataset, subjects, labels, split,
  class distribution, seed reporting, metrics, parameter/MAC evidence, and
  direct-versus-secondary provenance.
- **L2 unified reimplementation:** only V2 baselines evaluated with the same
  manifests, causal preprocessing, labels, seeds, and metrics.

An L1 value can motivate a baseline but cannot establish superiority over V2.
Use `NR` for unreported parameter counts, seed handling, or protocol fields.
