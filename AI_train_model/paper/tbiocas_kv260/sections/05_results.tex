\subsection{Frozen Software Reference}

The folded FP32 reference reaches 90.0718\% balanced validation-window
accuracy. The signed INT16 emulator reaches 90.0462\%, preserves ictal-window
sensitivity at 90.7645\%, and agrees with the folded FP32 predictions on
99.9743\% of 3,898 validation windows. The exported tensor package occupies
10,030 B. These results establish the software deployment reference only.
