# Experiment Results

`reference/` contains the concise, machine-readable record for the selected
current reference. `archive/` retains previous ablations as research evidence;
these runs are not the default checkpoint and must not be presented as current
results.

Only small reproducibility artifacts belong here: JSON summaries, CSV policy
sweeps, reports, and selected plots. Raw EDF data, prepared NPZ files, and
continuous score arrays remain outside Git.
